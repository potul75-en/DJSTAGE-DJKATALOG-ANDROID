# DJ-KATALOG Android

Natywna aplikacja Android DJSTAGE.PL. Wersja źródłowa: FINAL 108. Żadne klucze ani hasła nie są przechowywane w repozytorium.

Automatyczny build GitHub Actions wytwarza testowy APK; produkcyjny podpisany APK wymaga klucza wydawcy w GitHub Actions Secrets i kontroli publikacji na Hostido. Zeskanowanie kodu QR nie może automatycznie zatwierdzić instalacji Androida.
